# Kronokairos

A free class schedule for online classes. Add classes, keep join links and passcodes handy, set page alarms, export calendar events, or share a schedule with classmates.

## Privacy and limits

Your schedule stays in this browser on this device; Kronokairos does not upload it to an app server. A share link contains schedule details, including meeting links and passcodes, so share it only in private chats. Screenshots used for AI import go to the AI service you choose.

Page alarms work only while the page is open and the device is awake. Calendar alarms depend on your calendar app. The site works offline after its first visit.

## Publish with GitHub Pages

Upload the project files to a GitHub repository, keeping the `js`, `css`, and `icons` folders intact. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The site address will be `https://<username>.github.io/<repository>/`.
